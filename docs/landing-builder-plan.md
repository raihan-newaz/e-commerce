# Landing page builder and checkout plan

## Working now

- **Page design workspace:** visual sections, drag/reorder, style controls, responsive preview. Template choices live in a browser instead of occupying the editor top bar.
- **Checkout flow workspace:** product picker, one/many selection, minimum and maximum distinct products, coupon visibility and code management, and allowed payment methods.
- **Customer checkout:** variation buttons, quantity and delivery choices, coupon validation and recalculated totals. The server checks product membership, selection limits, stock, prices, payment availability, and discount again when an order is placed.
- **Payment:** cash on delivery and UddoktaPay when the store gateway is enabled. Online payment asks for an email receipt address.

## Next capabilities for a broader Elementor and CartFlows style builder

1. Nested columns and containers, reusable sections, and responsive overrides per device.
2. Page revisions, undo/redo across sessions, and staging for published pages.
3. Checkout field editor, bundles and order bumps, conditional display rules beyond product count, and analytics for funnel steps.
4. Coupon expiry, usage limits, eligibility rules, and reporting.
5. Automated browser checks for mobile, tablet, desktop, keyboard access, and complete payment callback flows.

Do not publish a sales page until its actual product, variation stock, price, images, and shipping details are set and reviewed.
